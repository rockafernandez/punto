Punto Privacy Policy

Effective date: October 10, 2026
Operator: Jenner Fernandez

Punto is a tennis tournament management project. This policy covers its current WhatsApp connectivity prototype, which receives test messages and sends an automatic acknowledgment. The prototype does not yet save match results or update tournament standings.

Information processed

When you message the configured WhatsApp number, the webhook receives your phone number, message content, message identifier, timestamp, and other metadata supplied by WhatsApp, which may include a profile name. It also receives delivery status events. The current prototype processes text messages from the configured test participant.

How information is used

Information is used to test message delivery, recognize the configured test participant, prevent repeated processing of the same message during a running session, send an acknowledgment, and diagnose connectivity problems. Message content is printed in the operator's local terminal. This prototype does not use messages for advertising or AI model training.

Storage and retention

The current prototype does not write incoming messages to a tournament database. Processed message identifiers are kept in memory and reset when the application stops. Text messages and technical errors may remain visible in terminal output; that output is not automatically deleted by the prototype and may be retained if saved for troubleshooting. Contact the operator to request deletion of test data under the operator's control.

Service providers

Meta's WhatsApp Cloud API delivers messages and sends replies. During local testing, Cloudflare Tunnel forwards webhook requests to the operator's computer. If this policy is hosted on GitHub Pages, GitHub handles requests to this page. These providers may process data and technical logs under their own policies, including outside your country.

Your choices and deletion requests

Participation in testing is voluntary. You can stop sending messages at any time. For questions, access requests, or deletion requests, email jenner.fernandez@outlook.com. Identify the WhatsApp number used for testing and describe your request. The operator may need to verify that the request concerns your data. Deletion requests cover data controlled by the operator; data retained by service providers is governed by their policies.

Security

The prototype checks Meta webhook signatures, keeps credentials in environment variables, and uses an HTTPS callback. Please do not send passwords, payment details, or other sensitive information during testing.

Changes to this policy

This policy will be updated before introducing features that change data handling, such as persistent result storage, additional participants, or processing voice notes and photos. The effective date above identifies the current policy.
